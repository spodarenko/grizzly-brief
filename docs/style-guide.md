# Стайл-гайд

Джерело значень — `src/config/`. Цей документ описує правила; при розбіжності спершу змінюється
документ, потім config.

## Кольори

База — Контур DS (`src/config/tokens.css`), акцент перевизначено під GRIZZLY.

| Токен                                         | Світла тема | Темна тема | Для чого                                  |
| --------------------------------------------- | ----------- | ---------- | ----------------------------------------- |
| `--brand`                                     | `#d61a55`   | `#ff5c8e`  | головна кнопка, обраний пакет, чекбокси   |
| `--brand-ink`                                 | `#ffffff`   | `#161616`  | текст на `--brand`                        |
| `--hi`                                        | `#fde8ef`   | `#3a1524`  | фон бейджів «Важливо», збережений блок    |
| `--hi-ink`                                    | `#a3123f`   | `#ff8fb1`  | текст на `--hi`, лічильник «обрано N з M» |
| `--stop`                                      | з канону    | з канону   | помилки                                   |
| `--bg / --layer / --line / --text / --strong` | з канону    | з канону   | фон, шари, лінії, текст                   |

Hex допускається лише в `src/config/tokens.css`.

## Кнопки

| Клас             | Вигляд                             | Де                                        |
| ---------------- | ---------------------------------- | ----------------------------------------- |
| `.btn.brand`     | фон `--brand`, текст `--brand-ink` | «Надіслати в WhatsApp», обраний пакет     |
| `.btn.secondary` | прозорий, рамка `--line-strong`    | «Обрати пакет», «Редагувати», «Скасувати» |
| `.btn` (базова)  | фон `--strong`                     | «Зберегти» в блоках питань                |
| `.btn.sm`        | менший розмір                      | кнопки всередині карток і callout         |

Підпис кнопки в обох станах узгоджений: «Обрати пакет» → «Обрано пакет».

## Типографіка

Шрифт `--font-mono` (IBM Plex Mono). Шкала — `src/config/typography.css`:
`--fs-2xs 11` · `xs 12` · `sm 13` · `base 14` · `md 15` · `lg 16` · `xl 18` · `2xl 20` · `3xl 22` · `4xl 28` (px).

- H1 — `4xl`, на ≤60rem `3xl`.
- Поля вводу на ≤60rem — `lg` (16px), інакше iOS зумить сторінку при фокусі.

## Відступи й брейкпоінти

- `--pad` бічний відступ: 5rem, на ≤60rem — **16px**.
- `--vpad` вертикальний відступ секцій: 4rem, на ≤60rem — 3rem.
- `--header-h` 80px; степер прилипає під хедером.
- `--stepper-pad` 24px: верх степера; у прилиплому стані — і низ. У звичайному стані низ = `--vpad`.
- Брейкпоінти (у media queries CSS-змінні не працюють): 65rem, 60rem, 55rem, 50rem, 44rem, 30rem.

## Текст

- Без англійських термінів для клієнта (scope, Tone of Voice, production-ready).
- Мова від імені студії: «ми», клієнт — «ви».
- Кожен текст має UA і RU версію.
